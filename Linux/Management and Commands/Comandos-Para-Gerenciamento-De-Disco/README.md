## Gerenciamento de Disco

### Informações importantes:

### Comandos utilizados:

- `fdisk` --> Comando utilizado para Verificar e Modificar discos no sistema.

- `cfdisk` --> Comando utilizado para Verificar e Modificar discos no sistema com uma interface mais agrádavel.

- `df` --> Comando utilizado para Verificar o espaço utilizado em disco no sistema.

- `/etc/fstab` --> Cominho do arquivo de configuração para montagem de discos.

- `mount` --> Comando utilizado para montar manualmente um disco no sistema.
